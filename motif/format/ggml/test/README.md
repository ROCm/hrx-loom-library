# GGML format checks

These private launch adapters exercise packed carriers and complete records
without giving the production motifs a launch ABI. Independent scalar-byte
references establish bit-field interpretation, coefficient application, and
rounding; they do not reuse the production unpackers or lane layout.

Direct-carrier checks isolate representation semantics. Record checks add real
byte origins, alignment, padding, and logical tails. Whole-storage comparisons
preserve input bytes and output guards. The owning source explains any numerical
allowance; scenarios and BUILD declarations own coverage and execution profiles.

Test roots and references remain outside production libraries. The
[development guide](../../../../docs/development.md#build-and-check) covers the
ordinary test and benchmark workflow.
