# Packed projection checks

These private launch adapters exercise the reusable projection schedules under
caller-owned row capacities, storage layouts, and target facts. Scalar-byte
oracles decode the original records independently of prepared layouts and
native matrix fragments. Small general inputs check arithmetic; nonzero
analytical workloads retain correctness coverage at larger extents.

Model tests reuse the same test-only references for fused epilogues and protocol
boundaries. They supply their own launch adapters without pulling references
into production providers. Complete comparisons preserve inactive rows, guards,
and immutable inputs even when live results have an explicit numerical bound.

Source overviews explain oracle independence and numerical acceptance;
scenarios own workload fanout. The [development guide](../../../../docs/development.md#build-and-check)
covers execution profiles, optional instrumentation, stress selection, and
benchmark measurements.
