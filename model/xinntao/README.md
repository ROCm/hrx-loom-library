# xinntao models

Models published by [xinntao](https://github.com/xinntao). Repackaged
checkpoints remain under the original base model's directory and are named
card variants.

[Real-ESRGAN x4plus](Real-ESRGAN-x4plus/OVERVIEW.md) supplies a four-times
image upscaler: one RRDBNet generator run over the whole image in a single
pass. The package has source programs, a geometry test, and a served image
check.
