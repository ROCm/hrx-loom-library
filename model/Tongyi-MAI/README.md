# Tongyi-MAI models

Models trained by [Tongyi-MAI](https://huggingface.co/Tongyi-MAI). Quantized
derivatives and repackaged checkpoints remain under the original base model's
directory and are named card variants.

[Z-Image-Turbo](Z-Image-Turbo/OVERVIEW.md) supplies an eight-step text-to-image
composition: a Qwen3 text encoder, a single-stream diffusion transformer, and a
tiled VAE decoder. The package has source programs, numerical tests, and a
served image check.
